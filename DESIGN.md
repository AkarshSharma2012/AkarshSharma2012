# Terminal profile

Flat terminal window, consistent monospace text, shell prompts, fastfetch-style columns, and white ASCII portrait. Inspired by [Andrew6rant](https://github.com/Andrew6rant/Andrew6rant) and [termfetch](https://github.com/saivarun1410/termfetch).

The first detailed ASCII-style portrait is restored using its white version. A 730 by 900 pixel crop and head outline exclude the shirt and hand; no new face imagery is generated in this revision. The portrait is reduced to fit the 498 by 498 display, with no source upscaling.

The GIF keeps the terminal still and rotates only the head between zero and three degrees. It holds still for 6.5 seconds between movements. A static PNG is selected for reduced-motion preferences. Animation timing is recorded in assets/animation.json.

Tool usage describes tasks, not measured percentages. Skills reflect public project sources. Raw source photos, credentials, age, email, and private repository information are excluded.
