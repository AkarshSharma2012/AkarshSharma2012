# Profile design

Custom terminal profile inspired by [Andrew6rant](https://github.com/Andrew6rant/Andrew6rant), [termfetch](https://github.com/saivarun1410/termfetch), and the [GitHub profile collection](https://github.com/abhisheknaiidu/awesome-github-profile-readme).

The supplied portrait was transformed using the built-in imagegen tool. Prompt: preserve identity, hair, protective glasses, headphones, red birds, blue shirt, and raised finger; replace the gym background with dark navy; create dense cyan/blue ASCII character art with no labels or watermark. The profile card and workflow are custom SVG compositions. profile.png is the portable display version; profile.svg is the editable source.

Tool usage describes tasks, not measured usage percentages. Skills reflect public project sources. No credentials, age, email, or private repository details are included.
