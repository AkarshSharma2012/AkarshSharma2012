# Terminal profile

Flat terminal window, consistent monospace text, shell prompts, fastfetch-style columns, and white ASCII portrait. Inspired by [Andrew6rant](https://github.com/Andrew6rant/Andrew6rant) and [termfetch](https://github.com/saivarun1410/termfetch).

The current portrait is sampled directly from the original user-supplied photo. No AI-generated facial imagery is used in this revision. A 410 by 510 pixel face crop is padded horizontally to preserve proportions, then sampled onto an 80-column by 66-row grid. A head outline excludes the gym background, shirt, and hand. All portrait glyphs are white. The portrait display is 498 by 498 pixels, smaller than the padded 510 by 510 source; no source upscaling occurs.

Tool usage describes tasks, not measured percentages. Skills reflect public project sources. Raw source photos, credentials, age, email, and private repository information are excluded.
